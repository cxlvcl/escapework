# ESCAPE Admin — установка на Windows / macOS и подключение к сайту

Это отдельное приложение с общей базой сайта **escapeworkspaceru.ru**. Изменения в панели сразу записываются в ту же MySQL. Для работы нужен интернет. Сначала установите серверное обновление, затем приложение.

## Обновление: автоматическое закрытие смен в 04:00

Уже установленную панель обновите повторным выполнением шагов 2–3 с новым `admin-update.zip`. Повторно создавать аккаунты и выполнять шаг 4 не нужно. Десктопное приложение переустанавливать не требуется.

При наступлении нового рабочего дня незакрытые смены поваров завершаются автоматически. В истории указывается «Автоматически в 04:00 МСК». Существующий CRON `snapshot.php` выполняет закрытие; если он задержался, следующий запрос к системе закрывает просроченные смены. Новая смена, открытая после 04:00, не закрывается повторным запуском CRON. До 04:00 смена остаётся открытой. Завершённые задания и фотографии сохраняются за прошлым рабочим днём, а для работы в новом дне повар должен открыть новую смену.

Функция использует историю смен установленной админ-панели MySQL. При пропуске нескольких запусков время завершения — первые 04:00 после открытия смены. Для смен, открытых до включения истории, отсчёт идёт от времени их обнаружения установщиком.

## Обновление сайта: задания холодильников для су-шефов

Загрузите новый `admin-update.zip` и повторите только шаги 2–3. Аккаунты, CRON и десктопное приложение менять не нужно.

На сайте войдите аккаунтом с ролью «Су-шеф», откройте «Станции», выберите станцию и прокрутите до блоков «Задания холодильника №…». Для каждого холодильника доступны добавление, переименование, перемещение вверх/вниз и удаление заданий. Редактирование относится только к выбранному холодильнику. Даже после удаления последнего задания блок управления остаётся и позволяет добавить новое.

Повар, шеф-повар и аудит не получают права редактирования. Удаление убирает задание из текущего чек-листа, сохраняя прошлые выполнения, фотографии и статистику. Счётчик холодильника показывает фактическое количество заданий. Эта функция предназначена для установленного MySQL-бэкенда с включённой историей админ-панели.

## Что входит

- Станции: создание, изменение названия и порядка, удаление из работы.
- Все задания: задания станций, холодильников, типы и экземпляры дополнительных заданий.
- Аккаунты: создание, изменение имени, логина, роли и пароля, удаление из работы.
- База фотографий: просмотр всех фотографий выполнения, добавление и замена набора из 1–4 фото, редактирование рабочей даты и автора.
- База данных: формы для 10 рабочих таблиц, включая холодильники, назначения поварам и выполнения. Системные таблицы, пароли, ключи и произвольные SQL-команды не открываются.
- Смены: текущие смены, история открытия/закрытия, станция и сотрудник, принудительное закрытие.
- Безопасность: ошибки входа, ограничения входа, отказы доступа, ошибки API, IP, повторения и число запросов по минутам.
- Журнал изменений: кто, когда и какую запись создал, изменил или удалил через админ-панель.

Сохраняются прежние возможности сайта: рабочий день с **04:00 МСК**, 1–4 фото, архив фотографий и иконка ESCAPE. Google Apps Script для этого обновления менять не нужно: админ-панель работает через MySQL на хостинге.

## 1. Подготовка

1. В панели хостинга сделайте резервную копию текущей MySQL (либо экспорт SQL через phpMyAdmin). Сохраните её в закрытом месте. Установщик отдельно сохранит файлы сайта, но это не заменяет копию базы.
2. Выберите существующий аккаунт су-шефа, шефа или аудита, которому нужен полный доступ. Его логин понадобится на шаге 4. Пароль остаётся прежним; отправлять его в чат не нужно.
3. Найдите в проекте файл **hosting/admin-update.zip**. Загружать нужно ZIP, а не эту методичку.

## 2. Загрузка на хостинг

В ispmanager откройте **Менеджер файлов → escape-private** и загрузите `admin-update.zip`.

Полный путь должен получиться таким:

```text
/var/www/u3638340/data/escape-private/admin-update.zip
```

## 3. Установка файлов

Откройте **Shell-клиент**, вставьте весь блок и нажмите Enter:

```bash
admin_update=$(mktemp -d /var/www/u3638340/data/escape-private/admin-update-XXXXXX) &&
unzip -q /var/www/u3638340/data/escape-private/admin-update.zip -d "$admin_update" &&
bash "$admin_update/install-admin.sh"
```

В конце должно появиться:

```text
Файлы установлены. Резервные копии: /var/www/u3638340/data/escape-private/admin-backup-XXXXXX
Следующий отдельный шаг: /usr/bin/php /var/www/u3638340/data/escape-private/admin-install.php
```

Сохраните настоящий путь резервной копии из вашего вывода. `XXXXXX` — пример, у вас будут другие символы. Если команда завершилась ошибкой, не переходите дальше: пришлите текст ошибки без конфигурации и паролей.

Установщик сохраняет существующие файлы, ставит зависимости перед основными PHP-файлами и не заменяет `.env`, `config.php` или папку фотографий. Сам по себе этот шаг ещё не выдаёт доступ администратора.

## 4. Включение панели и выдача доступа

Выполните **отдельной командой**:

```bash
/usr/bin/php /var/www/u3638340/data/escape-private/admin-install.php
```

Когда появится `Логин существующего администратора:`, введите выбранный логин и нажмите Enter.

Ожидаемый результат:

```text
Админ-панель включена. Полный доступ: Имя (логин).
Открытые ранее смены отмечены без выдуманного времени открытия.
```

Команда добавляет новые таблицы без удаления существующих данных. Доступ получает только указанный аккаунт; остальные су-шефы автоматически администраторами не становятся. Для другого администратора повторите эту команду и введите его логин.

Если возникла ошибка `CREATE command denied`, пользователь MySQL не имеет права создавать таблицы. Через phpMyAdmin импортируйте **только** `escape-private/admin-schema.sql` из нового ZIP в существующую базу, затем повторите команду. Не импортируйте начальную `mysql-schema.sql`: она предназначена для пустой базы.

## Два отдельных аккаунта: Артем и Виталий

Для этих аккаунтов подготовлен отдельный закрытый файл `hosting/admin-accounts.php`. Он не входит в общий ZIP. Этот вариант заменяет шаг 4: сначала выполните шаги 1–3, затем загрузите `admin-accounts.php` в **escape-private**, рядом с `admin-install.php`.

В Shell-клиенте выполните:

```bash
/usr/bin/php /var/www/u3638340/data/escape-private/admin-accounts.php &&
rm /var/www/u3638340/data/escape-private/admin-accounts.php
```

Будут созданы **Артем — cxlvcl** и **Виталий — vitashi** с полным доступом к панели. Пароли заданы отдельно и здесь не публикуются. Техническая роль на обычном сайте — «Аудит»; административные права назначаются независимо и включают управление аккаунтами, станциями и заданиями.

Существующие аккаунты с такими логинами не заменяются: при конфликте команда остановится. Повторный запуск после частичного сбоя безопасен для уже созданных этим скриптом аккаунтов и не сбрасывает их пароли. После полного успеха команда удаляет загруженный файл с хешами паролей.

## 5. Установка приложения

Готовые приложения находятся в папке проекта **desktop/release**.

### Windows, 64-bit

Откройте `ESCAPE-Admin-1.0.0-win-x64.exe` и пройдите установку. Будет создан ярлык ESCAPE Admin.

### Mac с Apple Silicon (M1 / M2 / M3 / M4 и новее)

Распакуйте `ESCAPE-Admin-1.0.0-mac-arm64.zip`, перенесите **ESCAPE Admin.app** в «Программы» и откройте.

### Mac с процессором Intel

Используйте `ESCAPE-Admin-1.0.0-mac-x64.zip`. Тип процессора указан в меню Apple → «Об этом Mac».

Это первая локальная сборка без сертификата издателя Microsoft и без нотариального заверения Apple. Система может запросить отдельное разрешение запуска. Разрешайте запуск только полученного из этого проекта файла; отключать защиту всей системы не требуется. Если macOS блокирует запуск, посмотрите «Системные настройки → Конфиденциальность и безопасность» после попытки открытия. Если появится другая ошибка, сохраните её текст.

Запустите приложение и войдите выбранным логином и прежним паролем. Приложение подключается только к вашему сайту. Реквизиты MySQL в него не вшиты.

## 6. Проверка после установки

1. В приложении откройте «Обзор»: должны показаться реальные станции и аккаунты.
2. В «Базе фотографий» откройте существующее выполнение и проверьте все его фото.
3. В «Сменах» проверьте список текущих сотрудников. Для смен, открытых до установки, время открытия неизвестно. Новые открытия и закрытия начнут записываться с момента включения панели.
4. На обычном сайте проверьте вход, задания и архив фотографий. Не выполняйте реальные задания ради проверки.
5. Откройте «Безопасность»: появятся новые события и счётчики запросов. Старые попытки входа задним числом не восстанавливаются.

Существующее задание CRON менять не нужно. Проверить его можно командой:

```bash
crontab -l
```

Должна остаться строка запуска `snapshot.php` в `0 4 * * *`. Она фиксирует статистику и очищает журналы безопасности старше 32 дней.

## Как пользоваться

**Станция и задания.** «Станции → Добавить», затем «Все задания → Задания станций → Добавить». Для холодильника сначала создайте его в «Базе данных → Холодильники», затем добавьте задания холодильника.

**Дополнительное задание.** Создайте его во «Всех заданиях → Дополнительные задания». Затем в «Базе данных → Назначения поварам» выберите задание и повара. Для нескольких поваров создайте отдельные назначения.

**Фото.** В «Базе фотографий» выберите нужную категорию. Кнопка «Фото · N» открывает набор. При редактировании выбранные новые фотографии заменяют весь набор; если ничего не выбирать, прежние сохраняются. Рабочая дата должна соответствовать времени выполнения с границей 04:00 МСК. Для просмотра можно искать по рабочей дате `2026-09-15`.

**Удаление.** Станции, аккаунты и справочники убираются из работы с сохранением истории. При удалении станции её открытые смены закрываются. Выполнения и назначения удаляются как записи; итоги затронутых закрытых дней пересчитываются в пределах 32 дней. Физические файлы фото при административном удалении не уничтожаются сразу. Для записей с историей перенос задания между станциями ограничен: создайте новое задание, чтобы старые фото остались у прежней станции.

**Доступ администратора.** Обычная смена роли на «су-шеф» не выдаёт полный доступ. Чтобы отозвать его, сначала назначьте другого администратора, затем выполните, заменив `LOGIN` на точный логин:

```bash
/usr/bin/php /var/www/u3638340/data/escape-private/admin-install.php 'LOGIN' --revoke
```

Последнего администратора отозвать нельзя. После отзыва можно удалить его аккаунт или сменить роль на повара обычным редактированием.

## Что означает раздел «Безопасность»

Он наблюдает за запросами, которые дошли до PHP API сайта. Показывает ошибки входа, отказ в доступе и нагрузку; от 120 запросов с одного IP за минуту отмечает всплеск. Это сигнал для проверки, а не подтверждение взлома или DDoS.

В журнал не попадают статические файлы, сетевые атаки и запросы, остановленные защитой хостинга до PHP. Для их анализа нужны журналы REG.RU или подключённой внешней защиты. Панель сама не является сервисом защиты от DDoS и не блокирует IP. За прокси журнал может показывать адрес прокси: неподтверждённые заголовки клиента намеренно не используются как источник IP.

Повторяющиеся ошибки объединяются по минуте, IP, типу и пути. Пароли, cookies и тела запросов не журналируются. Журнал изменений относится к операциям админ-панели; изменения напрямую через phpMyAdmin в него не попадут.

## Откат файлов

В папке резервной копии, показанной на шаге 3, есть `rollback-admin.sh`. Подставьте **ваш фактический путь** и выполните:

```bash
bash /var/www/u3638340/data/escape-private/admin-backup-XXXXXX/rollback-admin.sh
```

Это возвращает прежние PHP-файлы и публичные файлы сайта, а также прежнее состояние включения панели. Новые таблицы остаются в MySQL. **Изменённые или удалённые в панели записи откат файлов не восстанавливает.** Для восстановления данных понадобится резервная копия MySQL с учётом новых выполнений после её создания.

## Проверки сборки

Проверены серверные операции и права доступа, пользовательский сценарий панели с фотографиями и сменами, изоляция окна Electron на macOS, а также прежние сценарии сайта. Проверки серверной логики выполнялись с адаптером SQLite; отдельная реальная база REG.RU не изменялась. Windows-установщик собран, запуск на Windows и запуск ARM-сборки на Apple Silicon нужно проверить на соответствующем устройстве.
