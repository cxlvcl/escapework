# Фотографии для су-шефа и архив за 32 дня

Инструкция для действующего сайта **escapeworkspaceru.ru** на MySQL, в панели REG.RU / ispmanager, пользователь `u3638340`.

Обновление подготовлено и проверено локально. Для появления функции на сайте выполните шаги ниже.

## Что появится

- У су-шефа будет раздел **«Фотографии»** в меню компьютера и телефона.
- Внутри раздела появятся **«Сегодня»** и **«Архив фотографий»**. Кнопка архива открывает календарь: нажмите на дату, чтобы посмотреть снимки за этот рабочий день.
- Архив доступен су-шефу, шеф-повару и аудиту. Можно выбрать любой из **32 завершённых рабочих дней**; текущий рабочий день открывается кнопкой «Сегодня».
- Видны фотографии станционных, холодильных и дополнительных задач, в том числе задач, которые позднее скрыли. Открываются все прикреплённые снимки — от 1 до 4.
- Дата считается по рабочему дню **с 04:00 до 04:00 МСК**. Например, фото, сохранённое 16 сентября в 02:35, относится к рабочему дню 15 сентября. После 04:00 оно будет в архиве за 15 сентября.

Существующие фотографии сразу доступны по своим рабочим датам. Дополнительного переноса данных для архива не требуется.

## Шаг 1. Найти и загрузить архив

На компьютере откройте папку проекта **EscapeCheckList → hosting**. Найдите файл:

```text
photo-archive-update.zip
```

1. Откройте панель хостинга, затем **«Менеджер файлов»**.
2. Перейдите в папку **escape-private**.
3. Загрузите **photo-archive-update.zip**. Если загружаете эту версию повторно и панель спрашивает о совпадении имени, выберите «Заменить».
4. Дождитесь зелёной надписи **«Загрузка завершена»**.

Полный путь загруженного архива на сервере:

```text
/var/www/u3638340/data/escape-private/photo-archive-update.zip
```

Для установки нужен именно этот ZIP. Файл `PHOTO_ARCHIVE_UPDATE.md` — инструкция; загружать её отдельно не требуется. Архивы прежних обновлений `photos-update.zip`, `workday-update.zip` и `icon-update.zip` для этого шага не используются.

В новом архиве находятся `mysql.php`, `gateway.php`, страница сайта, JS/CSS, иконки ESCAPE, `manifest.json` и эта инструкция. Настроек подключения, паролей и данных базы в нём нет.

Откройте **«Shell-клиент»** в левом меню панели. Если в строке остался недописанный текст, нажмите **Ctrl+C**. Скопируйте весь блок ниже, вставьте в Shell-клиент и нажмите **Enter** один раз:

/usr/bin/php -l "$photo_archive_update/escape-private/mysql.php" &&
/usr/bin/php -l "$photo_archive_update/escape-private/gateway.php" &&

Дождитесь возвращения строки приглашения вида `[u3638340@server164 ~]$`.

Успешный результат: две строки **`No syntax errors detected`**, затем **«Архив фотографий установлен. Резервные копии: …»**. Сохраните указанный путь к резервным копиям: он понадобится только для возможного отката.

Если появилась ошибка и итогового сообщения об установке нет, остановитесь на этом шаге и сохраните текст ошибки. Выполнение блока прекращается на первой неуспешной команде. Если ошибка произошла после начала замены файлов, прежние версии уже находятся в указанном каталоге обновления.

Блок сначала проверяет PHP и создаёт резервные копии, затем устанавливает файлы; `index.html` переключается на новую сборку последним. Таблицы MySQL, `.env`, `config.php`, сохранённые фото и CRON на 04:00 продолжают использоваться. Повторный импорт, запуск `repair-workday.php` или обновление Google Apps Script для текущего MySQL-сайта не нужны.

## Шаг 3. Проверить на сайте

1. Откройте **https://escapeworkspaceru.ru** и обновите страницу. На телефоне закройте и снова откройте сайт или приложение с главного экрана.
2. Войдите под **су-шефом**. В меню должна появиться вкладка **«Фотографии»**; на телефоне она находится в нижней панели.
3. Откройте **«Фотографии → Архив фотографий»**. Должен открыться календарь с доступными датами за последние 32 завершённых рабочих дня. Стрелки позволяют перейти к предыдущему месяцу.
4. Выберите день, в который уже выполнялись задачи с фото. Над галереей будет написано **«Архив · выбранная дата»**, а ниже появятся снимки, сгруппированные по станциям и дополнительным задачам.
5. Откройте задание с несколькими снимками и пролистайте их стрелками. Старое выполнение с одним фото также должно открываться.
6. Нажмите **«Сегодня»**: откроются фотографии текущего рабочего дня. Снимки после полуночи и до 04:00 относятся к предыдущей рабочей дате.
7. При наличии доступа проверьте архив под шеф-поваром или аудитом. Поварам раздел архива недоступен.

Если за выбранный день нет выполнений с фотографиями, появится сообщение **«За этот рабочий день фотографий нет.»** Это нормальный пустой результат. Более ранние даты и будущие дни в календаре недоступны. Интервал доступных дат сдвигается каждый день в 04:00 МСК.

Если после установки вы видите прежний интерфейс, обновите страницу или заново откройте сайт в браузере. Если календарь открывается, но снимки не загружаются, сохраните дату, название задания и текст ошибки для проверки.

## Если потребуется откатить обновление

Этот шаг нужен только для возврата прежней версии файлов. Он не отменяет выполнения задач и не меняет данные базы.

Найдите путь из сообщения **«Резервные копии: …»** после установки. В первой строке следующего блока замените `ВСТАВЬТЕ_СУФФИКС` на реальный суффикс каталога. Пример формы имени: `photo-archive-update-Ab12Cd`.

```sh
photo_archive_restore='/var/www/u3638340/data/escape-private/photo-archive-update-ВСТАВЬТЕ_СУФФИКС'
test -f "$photo_archive_restore/mysql.php.before" &&
test -f "$photo_archive_restore/gateway.php.before" &&
test -f "$photo_archive_restore/www.before.tar" &&
/usr/bin/php -l "$photo_archive_restore/mysql.php.before" &&
/usr/bin/php -l "$photo_archive_restore/gateway.php.before" &&
install -m 644 "$photo_archive_restore/mysql.php.before" /var/www/u3638340/data/escape-private/mysql.php.restore &&
install -m 644 "$photo_archive_restore/gateway.php.before" /var/www/u3638340/data/escape-private/gateway.php.restore &&
mv -f /var/www/u3638340/data/escape-private/mysql.php.restore /var/www/u3638340/data/escape-private/mysql.php &&
mv -f /var/www/u3638340/data/escape-private/gateway.php.restore /var/www/u3638340/data/escape-private/gateway.php &&
tar -xf "$photo_archive_restore/www.before.tar" -C /var/www/u3638340/data/www/escapeworkspaceru.ru &&
echo "Прежняя версия файлов восстановлена. Обновите страницу сайта."
```

Резервные копии остаются в `escape-private`. Дополнительные файлы новой сборки в `assets` можно оставить: восстановленная страница использует прежние файлы.

## Справка о проверках и сборке

Пройдены 35 автоматических тестов серверной логики, восемь прежних браузерных сценариев PHP-приложения и новый сценарий архива в PHP-сборке и Next.js. Проверены права ролей, крайняя доступная дата, смена рабочего дня в 04:00, все три категории задач, скрытая задача, старые фото, наборы до четырёх снимков, календарь, переходы и пустой день. Проверены мобильный и настольный интерфейсы, сборки, TypeScript и ESLint. PHP проверен на реальном классе `MysqlBackend` с изолированным адаптером SQLite; рабочая база при проверках не использовалась.

Блоки установки и отката из этой инструкции выполнены на временной копии структуры сайта: файлы устанавливаются и восстанавливаются, настройки и фотографии сохраняются. Отдельно проверено, что синтаксическая ошибка в PHP останавливает установку до замены файлов сайта.

Для повторной сборки из исходников: `npm run build:hosting`. Для отдельной установки с Google как основной базой обновлены исходники и `google/dist/Code.js`; такая установка требует согласованного обновления её интерфейса и Apps Script. Команды этой инструкции предназначены для текущего сайта на MySQL.
